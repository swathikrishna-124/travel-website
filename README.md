# Travel Explorer Website

## About the Project
Travel Explorer is a travel website built using HTML and CSS. It showcases popular travel destinations and travel packages through a simple, user-friendly interface.

## Features
- Travel destination showcase
- Travel packages section
- Multiple web pages with navigation
- Images and multimedia content
- Simple and attractive design

## Technologies Used
- HTML5
- CSS3

## Project Pages
- Home
- About
- Packages
- Gallery
- Contact

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
